# Fix Root Causes

修真故障，别只修症状冒头的地方。根因是系统第一次干了不该干的事，或者没处理好一个本该处理的状态的那个位置。

- 先复现。一路追问「为什么」，直到答案落到代码里某个错误决策上。卡住时加打点直接读真实状态。
- 问清触发症状的状态本身合不合法。如果合法，就在代码出岔的地方把它处理好；如果这个状态本就不该存在，在症状处加判空或拦阻只会把 bug 藏起来，必须追出是谁造出了它。防御性判断、盲目重试、吞掉异常、硬截断数值和直接丢弃状态，是最常见的掩盖 bug 手段。
- 修掉整类模式，不只修眼前这一个点。把仓库里犯同样毛病的地方全找出来。
- 如果最后决定胜负的那个事实费了老大劲才挖出来，顺手提议加一个低成本的常驻信号，让下次一眼就能看见。
