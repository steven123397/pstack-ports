### Visual parity

**像素级等价对齐归你把关。基线就是规格标准，绝不许碰基线。** 等价与否靠图像 diff 判定，不靠肉眼估摸。

1. 动任何迁移之前先把基线建起来：搭一套视觉回归 `harness`，把现有组件在各种状态下的截图全部抓下来（如果是比对两套实现，也同时抓目标端）。没有基线，就没有资格宣称对齐。这是前置阻塞项，不是事后补课。
2. 写明并死守防偷懒红线：不许改 `harness`，不许篡改基线图，不许为了凑过 diff 而强改组件结构。要是觉得基线图本身有问题，停下来问人，绝不擅自改基线。
3. 一次迁移一个组件。按组件分 `worktree` 并行推进，每个组件配一名主理代理（`owner`，遵循 **separate-before-serializing-shared-state** `principle`）。共享底层原语作为前置阻塞阶段最先迁移。
4. 通过 control `skill` 在匹配的真实运行端上对每个组件跑基线图像 diff。只要 diff 不为零就是不通过，必须追查像素偏差来源。对每个组件跑 `/loop`，直到像素 diff 归零。
5. 按单个组件或安全批次执行 **Opening a PR**。

**Reply：** 已迁移的组件、每个组件的 diff 结果、基线 `harness` 位置，以及还剩哪些未迁。
