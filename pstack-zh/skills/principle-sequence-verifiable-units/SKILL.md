# Sequence work into verifiable units

把工作排成一个个以可检查状态收尾的小单元，当前单元没变绿前绝不进入下一个。

在全库清扫、迁移或成批同类修改里，每个单元都是一个固定节拍：已知良好状态、做一处改动、跑完检查、继续下一步。哪怕是脚本自动改的，也要坚持跑完每单元检查。

按能自证清白的顺序组织交付。失败测试在前，修复提交在后。先做减法清理，再做结构重塑。先量基线，再上改动。每个 commit 都能独立站得住、独立合入。
