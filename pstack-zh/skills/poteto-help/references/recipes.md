# 值得直接照抄的 `prompt`

把尖括号里的路径、`skill` 名和完成条件换成你自己的就行，措辞口语随意完全没问题。

## 读懂代码与上下文

- `/poteto-mode 读一下 <thread>，用大白话复述底层到底出了什么问题。`
- `/in-your-own-words <一段长或杂乱的需求>`
- `/sharpen <你正准备发出去的那条 prompt>`
- `/poteto-mode 调查一下 <症状> 为什么会发生。把已知事实、你查了哪些数据，以及最可能的假设列给我。先别改代码。`
- `先用 /how 摸清 <子系统> 是怎么运作的，再用 /why 查清它最近为什么坏了。`
- `/recall 找回我上周在 <话题> 上的进度，然后读一下 <issue>。`
- `/teach 讲讲你为什么选了这种写法而不是 <另一种写法>。你权衡了哪些利弊？`
- `/poteto-mode 接手这个分支。读一下决策日志，查清哪些已经做完了，顺着继续干，别把干完的活重做一遍。`

## 开发与修复

- 修 bug：`/poteto-mode <症状>。先复现，再修复并验证。`
- 应用内修 bug：`/poteto-mode 用 /verify-<app> 复现一下。如果在 main 上能复现，就修好并录段视频证明。`
- 有便宜单测的 bug：`/poteto-mode 先复现 <bug>。如果有便宜好跑的本地测试路径就走 /tdd，然后修复并重跑。`
- 做新功能：`/poteto-mode 新增 <行为>。<现有输出> 必须保持逐字节一致。两种都验证一遍。`
- 重构：`/poteto-mode 把 <代码> 收拢到一个模块里，零行为变更。先记下当前输出，改完证明完全不变。`
- 性能优化：`/poteto-mode <操作> 在 <测试数据> 上要跑 <耗时>。抓个 trace，修掉实测瓶颈，把优化前后对比发我。`

## 设计与计划

- `/poteto-mode 给 <功能> 做几个原型方案，截图或录屏发给我对比。`
- `/poteto-mode 我们需要 <功能>。先 /architect 一下，开放问题拿原型验证。继续实现前先让我看一眼。`
- `/poteto-mode 先写一篇教程示范怎么用 <新包>，然后 /teach 我它为什么比现在这套更好。`
- `让 /arena 对这个讨论串和我们现在的方案给个第二意见。`
- `/poteto-mode 把这份设计转成实施计划。拆成小步可验证的 PR，每个 PR 配好自己的验证步骤。`
- `/poteto-mode 规划把 <旧库> 迁到 <目标库>。拆成小步可验证的 PR。结果必须跟原版一模一样，连原有 bug 也照留。`

## 审查与合入

- `/interrogate 审一下整个分支，带着怀疑的眼光看。先别改代码。除非是真 bug 或行为回归，不要报吹毛求疵的小毛病。`（交回报告后顺便把 Dropped 列表也看一眼。）
- `/create-formal-verification-skill 证明 <模块> 在 <步骤> 交错或重试时始终满足 <属性>。`（该代码后续合并或重构后补跑 `/maintain-formal-verification-skill`。）
- `/swarm 用各自的检查脚本把 <目录> 下面每个包都验一遍。一包一个工人，汇总成一份报告。`
- `/poteto-mode 开一个 PR。整理成小步有序的 commit，描述里带上实跑证据。`
- `/poteto-mode 盯着这个 PR，把它跑绿。`（只问现状时改说：`/poteto-mode 看看 PR <编号>，还有什么没清的吗？`）
- `/poteto-mode 把这叠 PR 合入主干。`

## 挂机离开与回来复盘

- `/poteto-mode 我去睡了。从 <base> 拉个新 worktree 完成 <目标>。完成标准是 <检查项>。记好决策日志。提交 commit 前不用问我。/loop 直到完成为止。如果跑了几个小时确实卡死了，停下来把原因写清楚。`
- `/show-me-your-work 给我过一遍你昨晚干了什么。`（回来后先看末尾的 Attention 一节。）
- `/ketchup`：快速同步自你上一条消息以来这场对话发生了什么，并列齐所有等你拍板的事项。
- `/poteto-mode 这条队列跑 full autopilot，每项彼此独立。`
- `/poteto-mode 这些改动跑 autopilot，但别点 merge，我自己来合。`
- `/reflect 把这次学到的教训收进 skill，下次别再重复踩坑。`（只批准真正会改变未来决策的改动。）
- `/bro`：把上一条回复用毫无术语的大白话重说一遍。
