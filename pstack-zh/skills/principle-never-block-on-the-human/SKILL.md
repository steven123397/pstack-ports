# Never Block on the Human

人类是异步监督的，代理必须保持畅通推进，别自己卡死。做出合理判断，直接动手干，事后留给人来纠偏。代码改动既可撤回又可评审，一次做错的代价通常远小于停在原地干等。

- 先做出来，再拿给人看。干完活把结果摆出来，别问「我该不该做 X？」，直接做完 X 再说明为什么这么做。
- 让系统能自愈。发现问题就记下来，下一轮直接修掉。
- 不可逆操作（force-push、删生产数据、对外发消息）依然必须先确认。
- 可逆操作（写代码、改笔记、拆任务）直接推进，不要卡住等人。
- 产品方向由人定，执行过程不要卡死。
